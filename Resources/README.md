# Untracked runtime resources

Runtime material is intentionally absent from this repository.

Only this README is tracked below `Resources/`. Do not add `Configs`, `Data`, `table`, `table-4.6.0`, client material, saves, certificates, logs, or generated deployment output.

Use an external private data root with `tools/verify-runtime-data.ps1` and `tools/publish-runtime.ps1`. `Schemas/table/` is compile-time metadata and must never be used as gameplay data.
